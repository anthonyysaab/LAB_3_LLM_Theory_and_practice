# LAB_3_LLM_Theory_and_practice

Solution files for Lab 3 of Theory and Practice of LLM at Paris Cite.

## Repository Layout

- `train_model.py` - first character-level GPT experiment.
- `corpus_cleaning_script.py`, `Read_corpus_script.py`, `Fetch_poetry_corpus.txt` - first corpus collection and cleaning utilities.
- `Useful Files/` - first experiment corpus, artifacts, samples, and checkpoint placeholders.
- `Experiment II/` - second experiment script, dataset link, artifacts, samples, and checkpoint placeholders.
- `plots/` - loss-curve plot exported from the first experiment.
- `lab3.pdf` and `Report_Lab_3_Anthony_Saab.pdf` - lab/report PDFs.

Large model checkpoints and raw 60MB+ datasets are intentionally kept out of Git. See `MERGE_NOTES.md` for the local source paths and merge audit.
